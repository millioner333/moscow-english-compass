# Moscow English Compass

Сделай мульти страничный сайт для курсов английского языке в Москве, сайт должен иметь продуманную структуру, красивый дизайн который соответствует нише курсов английского языка. На сайте должны такие страницы Главная, О нас, Курсы, Цены, Преподаватели, Вакансии, Контакты.
